# المصحف الإلكتروني 📖

تطبيق ويب (PWA) لقراءة القرآن الكريم بالخط العثماني، قابل للتثبيت على الهاتف ويعمل **بدون إنترنت** بعد أول استخدام.

## الملفات
```
mushaf/
├── index.html      ← التطبيق نفسه
├── manifest.json   ← بيانات التثبيت (اسم، أيقونة، ألوان)
├── sw.js           ← Service Worker المسؤول عن العمل أوفلاين
├── icons/
│   ├── icon-192.png
│   ├── icon-512.png
│   └── apple-touch-icon.png
└── README.md
```

## 1) رفعه على GitHub
```bash
cd mushaf
git init
git add .
git commit -m "المصحف الإلكتروني - أول نسخة"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

## 2) استضافته مجانًا عبر GitHub Pages (لازم لتثبيته على الهاتف)
1. من صفحة الريبو على GitHub: **Settings → Pages**
2. من **Source** اختر: **Deploy from a branch**
3. اختر **Branch: main** و **/ (root)** ثم **Save**
4. بعد دقيقة تقريبًا سيظهر الرابط بالشكل:
   `https://USERNAME.github.io/REPO/`

> ⚠️ مهم: PWA (والعمل أوفلاين تحديدًا) **لا يعمل** على رابط `file://` مباشرة، ولازم يكون عبر `https://` — ولهذا GitHub Pages هو الحل الأسهل والمجاني.

## 3) التثبيت على الهاتف
افتح رابط GitHub Pages من متصفح الهاتف (Chrome على أندرويد أو Safari على آيفون):

**أندرويد (Chrome):**
- بعد فتح الرابط ستظهر رسالة "إضافة إلى الشاشة الرئيسية" تلقائيًا، أو من قائمة ⋮ اختر **"تثبيت التطبيق" / Add to Home screen**

**آيفون (Safari):**
- زر مشاركة (المربع مع السهم) → **"Add to Home Screen" / إضافة إلى الشاشة الرئيسية**

بعدها ستجد أيقونة التطبيق على شاشة الهاتف الرئيسية وكأنه تطبيق عادي مثبت.

## 4) كيف يعمل بدون إنترنت؟
- أول مرة تفتح فيها أي سورة (وأنت متصل بالإنترنت) يتم حفظها تلقائيًا على الهاتف.
- بعدها تقدر تفتح نفس السورة بدون إنترنت أبدًا وستظهر فورًا من الحفظ المحلي.
- في الصفحة الرئيسية للتطبيق يوجد زر ⇩ بجانب زر الوضع الليلي: بالضغط عليه (وأنت متصل بالإنترنت مرة واحدة) يتم **تنزيل القرآن كاملًا (114 سورة)** دفعة واحدة، وبعدها يعمل التطبيق بالكامل أوفلاين دائمًا.
- شكل التطبيق (التصميم، الخطوط، الأيقونة) يُحفظ أيضًا تلقائيًا من أول فتح.

## ملاحظات
- المفضلة وآخر آية قرأتها محفوظة محليًا في الهاتف (localStorage) حتى لو أغلقت التطبيق.
- مصدر بيانات القرآن: [alquran.cloud](https://alquran.cloud) (نص عثماني، مجاني بدون حاجة لمفتاح API).
